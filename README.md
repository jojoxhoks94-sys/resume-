# Jordan Hooks Responsive Portfolio

## Files
- `index.html` — resume, skills, achievements, and project gallery
- `hobbies.html` — hobbies and interests
- `contact.html` — public-facing contact page
- `style.css` — shared styling, Flexbox, CSS Grid, and responsive media queries
- `images/profile.jpg` — add your profile image here

## Open the website
1. Download or clone the repository.
2. Keep the HTML files, `style.css`, and `images` folder together.
3. Add your profile photo as `images/profile.jpg`.
4. Open `index.html` in a web browser. Use the navigation to visit Hobbies and Contact.

## Responsive testing
Use your browser's developer tools and device toolbar to test approximately 1200px, 800px, and 400px widths.

## Notes
The project gallery currently includes example descriptions for interests and planned work. Replace them with real project details as you complete projects. The contact email is a sample address; replace it with an address you want to publish.
